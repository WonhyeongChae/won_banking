문제점
1. 가상머니로 리허설을 진행하면 실제 자본으로 영업을 할 때와 다르게 행동할 수 있다(서비스 듬뿍, 무조건 많이) -> 리허설 결과에 따라 상품 가입 시 혜택(이자 감면, 대출 한도 증가)이 있도록 하면 충분한 동기부여
2. 기업 금융은 우리 사업부가 아니다 -> 기업 금융 자체를 가져오는게 아님. 기존 사업자를 끌어오는게 아니라 개인 고객 중 예비 창업자를 우리은행 플랫폼에 유입시키고 이러한 과정에서 관련 상품 연결, 기업 금융으로의 연결 제공 가능성
3. 리허설 시뮬레이션 구축 방안 -> 소상공인365의 상권 정보 모델 학습 => 실시간 이벤트 생성 => 사용자의 행동
4. 상권 정보만 가지고 어떻게 학습? -> 언어모델 파인튜닝 또는 해당 상권에 해당하는 실제 점포 데이터 확보?
5. 이미 소상공인365가 있는데 사용자가 이 기능을 사용할 이유? -> 소상공인365는 상권 정보만 제공, 이 기능은 예비 창업자가 능동적으로 모의 창업을 진행해보는 기능(일종의 이미지 트레이닝?)
6. 기간이 너무 길지 않나? -> 창업 준비기간이 평균 1년 정도, 충분히 가능
