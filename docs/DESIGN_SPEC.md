# 디자인 기준 v0.1

## 시각 방향
팀 표기: WON 플러스원. 로고에 적힌 명칭 기준이며 최종 팀명 확인 필요.
원본 로고의 파랑·하늘색·흰색을 활용. 아래 색상은 작업용 제안값이며 공식 우리은행 브랜드 규정이 아님.

| 토큰 | 값 | 용도 |
|---|---|---|
| navy | #10264D | 제목·본문 |
| blue | #0067D8 | 핵심 강조 |
| cyan | #18BCEF | 보조 강조 |
| background | #F3F8FE | 페이지 배경 |
| muted | #53657D | 설명 |

## 페이지 규격
A4 가로 841.89×595.28pt. 포스터에 화면 비율 규정 없음. 5페이지 고정.
안전 여백 36pt. 제목 26pt, 카드 제목 15pt, 본문 12pt, 출처·쪽번호 9pt.
맑은 고딕 사용 및 PDF에 포함. 긴 문장은 줄바꿈 후 넘침 검사.
페이지당 결론 1개, 근거 최대 3개. 제목 자체가 핵심 주장을 전달하도록 수정.

## 로고
assets/originals/team_logo.png 원본 비율 유지. 정사각형 배치, 자르기·왜곡 금지.
표지 우측에 배치하며 원본 배경색 유지. 로고 문구를 별도 공식 은행 로고로 해석하지 않음.

## 최종 시각화
2페이지: 출처가 있는 문제 근거. 3페이지: 핵심 화면 또는 서비스 구조.
4페이지: 고객 행동과 서비스 응답을 연결하는 이용 흐름.
5페이지: 실행 범위와 검증 지표. 미확정 수치 대신 측정 방법 우선 표시.
현재 PDF의 카드는 작성 안내용이며 실제 서비스 설명으로 교체 필요.
